🔹 STEP 1: Login to Railway
───────────────────────────────────────────────────────────────
railway login

(Browser opens → Sign up/Login → Authenticate)

═══════════════════════════════════════════════════════════════

🔹 STEP 2: Initialize Project
───────────────────────────────────────────────────────────────
cd /Users/kudiratbello/trustescrow-ng
railway init

(Enter project name when prompted)

═══════════════════════════════════════════════════════════════

🔹 STEP 3: Add PostgreSQL
───────────────────────────────────────────────────────────────
railway add --database postgres

═══════════════════════════════════════════════════════════════

🔹 STEP 4: Create Upstash Redis
───────────────────────────────────────────────────────────────
Open: https://console.upstash.com
Create database → Copy TLS URL → Then:

railway variables set REDIS_URL="rediss://default:xxxxx@xxxxx.upstash.io:6379"

═══════════════════════════════════════════════════════════════

🔹 STEP 5: Set Environment Variables
───────────────────────────────────────────────────────────────
railway open

In Dashboard:
1. Click service
2. Variables tab
3. Raw Editor
4. Copy ALL from: railway-env-template.txt
5. Paste & Save

═══════════════════════════════════════════════════════════════

🔹 STEP 6: Deploy API
───────────────────────────────────────────────────────────────
railway up

(Takes 5-10 minutes - watch with: railway logs --tail)

═══════════════════════════════════════════════════════════════

🔹 STEP 7: Get Railway URL & Update
───────────────────────────────────────────────────────────────
railway status

(Copy your URL, then update:)

railway variables set APP_URL="https://YOUR-RAILWAY-URL.up.railway.app"

═══════════════════════════════════════════════════════════════

🔹 STEP 8: Test API
───────────────────────────────────────────────────────────────

Expected: {"status":"ok","db":"connected"}

═══════════════════════════════════════════════════════════════

🔹 STEP 9: Deploy Admin Dashboard
───────────────────────────────────────────────────────────────
cd /Users/kudiratbello/trustescrow-ng/apps/admin
vercel --prod

(Follow prompts - project name: trustescrow-admin)

═══════════════════════════════════════════════════════════════

🔹 STEP 10: Configure Admin Environment
───────────────────────────────────────────────────────────────
vercel env add NEXT_PUBLIC_API_URL production

(Enter: https://YOUR-RAILWAY-URL.up.railway.app)

vercel --prod

(Redeploy with environment variable)

═══════════════════════════════════════════════════════════════

🔹 STEP 11: Update CORS
───────────────────────────────────────────────────────────────
railway variables set ADMIN_CORS_ORIGIN="https://YOUR-VERCEL-URL.vercel.app"
railway up
